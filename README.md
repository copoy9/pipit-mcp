# Pipit — MCP server

The hosted MCP endpoint for the **Pipit** connector for Muse.
A single-file, zero-dependency Model Context Protocol server (Streamable HTTP transport).

- Entrypoint: `main.js` (works on Deno Deploy and Cloudflare Workers; exports a standard `fetch` handler)
- Tools: `pipit_about`, `pipit_latest_note`, `pipit_contact`
